# ASD-STE100 writing rules (working summary)

ASD-STE100 (Simplified Technical English) is a controlled language. It was made for aircraft maintenance manuals, so that readers, including non-native speakers, cannot misread an instruction. This is a working summary of its main writing rules, not the full specification. The real spec also has a dictionary of approved words.

## Words

1. Use simple, common words. Prefer `use` to `utilize`, `start` to `initiate`, `help` to `facilitate`, `about` to `approximately`.
2. Give each word one meaning, and use it only in that meaning. Do not use `run` to mean "execute" in one sentence and "operate" in the next.
3. Use one name for one thing. After you call it "the cache", do not call it "the store" or "the buffer".
4. Use verbs as verbs. Write "check the file", not "do a check of the file".
5. Do not use `-ing` forms as nouns or adjectives where a simple verb works. Write "to save the file", not "saving of the file".
6. Write technical names exactly. Explain each one at first use if the reader is a beginner.

## Sentences

7. **Instructions: 20 words or fewer. Descriptions: 25 words or fewer.**
8. Put one instruction in each sentence. If two actions happen together, you can put them in one sentence.
9. Use the active voice. Write "The server sends the reply", not "The reply is sent by the server".
10. Write instructions in the imperative ("Open the file.").
11. Keep articles (`the`, `a`) and short connecting words. Do not write in note-style: "Open file, check value" is wrong.
12. Do not use long noun clusters. Write "the error message of the login page", not "login page error message text".
13. Give conditions first: "If the light is red, stop the engine."

## Paragraphs

14. Put one topic in each paragraph, with no more than 6 sentences.
15. Start with the most important information.
16. Put a warning or a caution before the step it applies to, not after.

## The "80% of the way" version (default)

Karpathy's tip: full STE can feel stiff, so ask for "80% of the way". In practice:

- Keep rules 2, 3, 7, 8, 9, 13 and 15 strictly. They do most of the work.
- Relax rule 1 when a common phrase is clearer than the approved word.
- Allow one longer sentence in a paragraph when splitting it would break the logic.
- Allow a short example, an analogy, or a number in brackets.

## Quick self-check before output

- [ ] Each sentence is 25 words or fewer (20 for instructions).
- [ ] Each thing has one name all the way through.
- [ ] There are no passive sentences (or at most one per paragraph, if 80% mode).
- [ ] The first line says the main point.
- [ ] For a beginner, each term is explained once, in plain words, or not used.
